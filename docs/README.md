## چک‌لیست پیش از ارسال

- [ ] تکمیل مشخصات سازمان متقاضی و امضا/مهر اقرارنامه (مستند ۵) روی سربرگ رسمی؛
- [ ] تأیید **نوع گواهی درخواستی** در اقرارنامه و تطبیق مستندات با آن؛
- [ ] تهیه تصاویر صفحه‌های سامانه از محیط اجرایی و قراردادن آن‌ها در پوشه `images/` مطابق فهرست تصاویر مستند راهنمای کاربری (مستند ۴)؛
- [ ] بازبینی نهایی محتوای مستندات پیش از ارسال.
